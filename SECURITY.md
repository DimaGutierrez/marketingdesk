# Seguridad

No publiques claves, tokens, backups ni información de campañas en Issues o Discussions. Para un problema de seguridad, contactá al mantenedor mediante los canales de su portfolio y compartí inicialmente sólo una descripción sin secretos.

La versión actual usa una clave para un único espacio. No tiene cuentas individuales, permisos por rol ni limitador propio por IP. Un despliegue para varios clientes requiere ampliar ese modelo y revisar controles de abuso. La demo pública es de solo lectura y sus datos son ficticios.
